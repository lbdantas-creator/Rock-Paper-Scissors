
# Rock Paper Scissors

A browser-based Rock Paper Scissors game built with HTML, CSS, and JavaScript.

This project is part of [The Odin Project](https://www.theodinproject.com/) Foundations course.

## Features

- Play Rock, Paper, or Scissors against the computer.
- Choose your move using interactive buttons.
- Keep track of the player's and computer's scores.
- The first player to reach 5 points wins the game.
- Display a winner announcement in a pop-up modal.
- Restart the game and play again.

## Technologies

- HTML5
- CSS3
- JavaScript

## How to Play

1. Open the game in your browser.
2. Choose Rock, Paper, or Scissors.
3. The computer will randomly select its move.
4. The scores are updated after each round.
5. The first player to reach 5 points wins!

## Rules

- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- Matching choices result in a tie.
