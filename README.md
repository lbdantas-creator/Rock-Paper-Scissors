
# Rock Paper Scissors

## Description

This is a simple Rock Paper Scissors game built with JavaScript as part of my learning journey through The Odin Project's Foundations course.
The game allows the player to compete against the computer for five rounds. The computer randomly selects Rock, Paper, or Scissors, while the player enters their choice through a prompt dialog.
At the end of the game, the final scores are compared to determine the winner.

## How to Play

1. Run the JavaScript program in your browser.
2. Enter `rock`, `paper`, or `scissors` when prompted.
3. Play five rounds against the computer.
4. Check the console to see the result of each round and the updated scores.
5. View the final result to find out who won the game.

## Game Rules

- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- If both players choose the same option, the round ends in a tie.

Each round awards one point to the winner. A tie does not award any points.

## Features

- Random computer choices.
- Five rounds per game.
- Score tracking for both the player and the computer.
- Round-by-round results displayed in the browser console.
- Final game result displayed in an alert dialog.
